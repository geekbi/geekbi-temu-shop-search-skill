# Temu 店铺搜索

## 工作原则

- 只使用极鲸云返回的真实店铺数据，不编造店铺、指标或搜索结果。
- 将数据事实、基于数据的计算和分析判断明确区分。
- 默认使用简体中文，日期使用绝对日期，金额标明当前 Temu 站点币种。
- 对缺失值、异常值、样本量和未完成分页作显式说明，不用缺失数据支撑强结论。
- 接口参数、响应字段、请求命令和原始 JSON 仅用于内部调用。进度说明、分析过程和最终答复使用中文业务名称，不展示英文参数；只有用户明确要求开发对接或故障排查时才展示必要技术信息。

## 执行流程

1. 明确用户要找特定店铺、筛选竞品、寻找新店，还是研究头部店铺的经营表现。
2. 明确站点、店铺名称或 ID、类目、开店时间、经营规模和托管模式等必要条件。未指定站点时默认美国站，并在结果中说明。
3. 读取 [Temu 店铺搜索接口](Temu店铺搜索接口.md)，生成最小必要查询条件。未指定站点或明确要求美国站时直接使用美国站默认值；只有用户指定其他国家或地区时，才运行 `scripts/temu_site_list.py` 实时解析站点。用户要求热销店铺、热销新店或最近开店等榜单时，再读取 [Temu 店铺榜单查询预设](Temu店铺榜单预设.md)。
4. 使用 `scripts/temu_shop_search.py` 发起查询；服务端要求暂停查询时，按 [查询暂停与恢复流程](查询暂停与恢复流程.md) 提示并暂停。
5. 恢复条件满足后原样重跑查询，取得店铺数据后再分析。
6. 查询失败时，只向用户提示错误输出一级 `msg` 的中文文案，不展示错误 JSON、状态码、异常栈或内部字段。
7. 检查分页范围、样本量、关键字段和更新时间后再分析；未读取全部分页时明确标为样本。

## 查询策略

- `keyword` 可匹配店铺名称或店铺 ID。用户给出明确店铺名称或 ID 时优先使用关键词查询。
- 店铺搜索使用 Temu 通用站点 ID。美国站直接使用默认值 `48` 且不请求站点列表；其他国家或地区使用 `scripts/temu_site_list.py --country "国家或地区名"` 实时查询，只有唯一精确匹配时才将返回的站点 ID 传给店铺搜索。
- `catIds` 使用 Temu 通用类目 ID，不存在独立的店铺主营类目 ID。只使用用户明确给出或极鲸云数据中已确认的可信 ID，优先一级或二级类目。没有可信 ID 时不根据类目名称猜测；省略 `catIds` 并仅按店铺关键词搜索，或请用户提供明确 ID。
- 一般在关键词和类目中选择一个主条件；只有用户明确要求在某类目内查特定店铺时才组合，且说明结果可能显著减少。
- 用户未指定排序时，根据问题选择一个最相关指标；寻找大卖优先按店铺总销量或总销售额降序，寻找高成长店铺优先筛选月均销量和月销量增长率，寻找新店优先限制开店时间后再按经营规模降序。
- 不为凑结果擅自放宽用户明确给出的销量、销售额、评分、粉丝数、商品数、客单价或时间范围。
- 服务端为每个店铺返回 `linkUrl`，指向该店铺在极鲸云的 Temu 店铺详情页。每个被展示的店铺都必须把店铺名称写成 `[店铺名称](<linkUrl>)`；这条规则适用于表格、列表、排名、候选清单和正文，不因用户未主动要求链接或要求简洁结果而省略。

## 分析方法

从以下维度评估店铺，不仅按单一销量排名：

- 经营规模：店铺总销量、总销售额、商品数量、粉丝数和评论数。
- 近期表现：结合日、周、月均销量与销售额，及其增长率判断加速或回落，不用单一时间窗口下结论。
- 商品与定价：经营类目、平均价格及商品数量，判断价格带和铺货深度。
- 动销效率：结合动销商品数和动销率，区分“商品多但动销弱”与“规模不大但单品效率高”的店铺。
- 口碑：店铺评分与评论规模结合观察，避免用少量评论的高评分作强结论。
- 发展阶段：结合开店时间与经营规模识别新店、高成长候选或成熟大卖。
- 经营模式：区分全托管和半托管后再比较，不把不同模式的店铺直接横向排名。
- 风险与限制：日、周、月指标可用于识别近期趋势，但不等于完整历史时序。本能力不提供单品明细和完整上新节奏，需要时明确标注为未验证项。热度仅作辅助指标，没有明确口径时不单独用它下结论。

只有指标属于同一站点和可比口径时才计算店均、品均或占比。用总销售额除以商品数量等派生指标时，说明公式并排除分母为零或缺失的样本。

## 输出要求

店铺表格或清单的名称列必须使用 `[店铺名称](<linkUrl>)`。发送答复前逐行检查：服务端返回非空 `linkUrl` 的每个店铺都必须存在对应的可点击店铺名称，缺少任何一个都先修复再交付。

用户只索要店铺链接时，仅返回 `[店铺名称](<linkUrl>)`，不附加接口、字段、链接类型或缺失状态说明。

默认按以下顺序输出：

1. 一句话结论。
2. 数据口径：站点、条件、排序、分页范围、样本量和更新时间。
3. 候选店铺：中文展示核心指标和入选原因。
4. 经营特征与竞争判断：区分事实、计算和判断。
5. 风险、数据限制和下一步验证动作。

如果用户只要求搜索结果，保持简洁，不强行扩展为完整竞品报告。
