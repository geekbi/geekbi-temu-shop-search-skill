# 查询暂停与恢复流程

业务脚本先正常查询数据。服务端因未登录、额度不足、请求受限、需要充值、开通或升级等原因要求暂停查询时，按以下流程处理：

1. 使用服务端返回的中文 `msg` 提示用户，不改写提示含义。
2. 服务端返回 `jumpUrl` 时，将其展示为可点击的 Markdown 链接；没有返回时不自行生成链接。
3. 暂停数据查询，不展示原始 JSON 或内部状态字段，也不在尚未取得数据时生成选品或市场分析结论。
4. 用户完成提示要求的操作、等待限制解除或回复“继续”后，原样重跑原业务脚本。
5. 恢复条件仍未满足时，继续使用服务端最新的提示；有跳转链接时继续展示该链接，不创建并行操作。
6. 跳转链接失效时重新运行原业务请求，使用服务端新返回的提示和链接。

服务端只返回提示而没有跳转地址时，直接展示提示并停止本次查询。普通查询错误也只展示服务端一级 `msg`；没有有效提示时再使用脚本生成的中文错误。

## 信息保护

- 查询鉴权和暂停状态统一由公共请求脚本处理，业务脚本直接复用。
- 所有极鲸云 Temu Skills 共用同一个系统用户配置路径和同一份鉴权状态；任意一个 Skill 完成登录后，其他 Skill 优先复用该状态，有效期内不重复登录。
- 登录凭据依次保存到共享的系统用户配置目录、当前 Skill 目录的 `.geekbi/agent-auth.json` 和当前工作目录的 `.geekbi/agent-auth.json`；读取时也按照这一优先级选择首个存在的副本。
- 不手工复制、输出或传递登录状态文件；跨 Skill 复用由公共系统配置路径自动完成。
- 不向用户展示访问令牌、设备码、回调凭据、权限标识、请求头或内部状态对象。
- 不把账号、密码、密钥或令牌写入 Skill 文档、示例、回答、日志或命令行参数。
