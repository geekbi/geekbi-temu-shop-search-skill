# Temu 店铺榜单查询预设

根据用户的榜单或竞品店铺调研意图选择一个查询预设，并以用户明确提出的条件为准。

## 使用规则

- 每次只选择一个最贴近用户意图的主预设；除非用户明确要求，不叠加多个预设。
- 在预设之外补充站点、页码和每页数量，可按需增加关键词或类目。用户的明确条件优先于预设。
- 排序方向统一使用 `desc` 或 `asc`。
- 未指定或指定美国站时使用默认值，其他国家或地区先实时查询站点列表。
- 将“近 3 个月”换算为查询执行时刻减 3 个自然月至执行时刻，传绝对 ISO 8601 时间。
- 预设只定义筛选和排序，不代表命中店铺必然是“大卖”或“潜力店”；取得数据后仍需结合销量、增长率、动销率、商品数、口碑和开店时间验证。

以下参数块省略站点、分页及所有未设置参数。

## 查询预设

### 热销店铺

适用于“热销店铺”“头部竞品店铺”“总销量最高的店铺”等请求。

```text
sort=mallSold
order=desc
```

### 高评论店铺

适用于“评论规模大的店铺”“评价样本多的店铺”等请求。

```text
sort=reviewNum
order=desc
```

评论数反映反馈样本规模，不等同于高评分或好口碑；还需结合店铺评分和近期经营表现判断。

### 热销新店

适用于“最近三个月的热销新店”“近期潜力店铺”等请求。

```text
mallOpenTimeMin=<执行时刻减3个自然月的ISO时间>
mallOpenTimeMax=<执行时刻的ISO时间>
sort=mallSold
order=desc
```

该预设先限制近 3 个月开店，再按店铺总销量降序。对候选店铺下“潜力店”结论前，还要检查月均销量、月销量增长率和月动销率，避免把靠单一历史爆款累积销量的新店当成持续增长店铺。

### 最近开店

适用于“最近开的店”“最新入场店铺”等请求。

```text
sort=mallOpenTime
order=desc
```

按开店时间从新到旧排序，不自动增加“近 1 个月”或“近 3 个月”条件；用户明确给定时间范围时再补充。

## 生成请求前检查

1. 是否只选择了一个主预设。
2. 美国站是否使用默认值，其他站点是否已通过实时站点列表解析。
3. 相对时间是否已转换为绝对 ISO 8601 时间。
4. 排序方向是否只使用 `asc` 或 `desc`。
5. 查询参数是否全部存在于店铺搜索接口契约中。
6. 是否区分了总销量、评论规模和店铺评分，避免混用不同口径。
7. 是否按用户明确条件调整预设，并在数据口径中说明。
